# Баг: сброс страницы Attachments после закрытия диалога задачи

## Как воспроизвести

1. Открыть в левом меню раздел **Attachments**.
2. В списке файлов нажать ссылку на задачу у любого attachment.
3. Убедиться, что открылся диалог редактирования этой задачи.
4. Закрыть диалог.

## Фактическое поведение

После закрытия диалога страница сбрасывается и открывается другая страница.

## Ожидаемое поведение

После закрытия диалога пользователь остаётся на странице **Attachments**, с которой открыл задачу.

## Требование

Исправить навигацию так, чтобы открытие и закрытие диалога задачи из списка attachments не уводило пользователя со страницы **Attachments**.
